## 2. 排版与样式约定

所有字号以 `rem` 定义，下表数值以浏览器默认字号 16px 为例。调整全局字号、行高和颜色的入口是 `frontend/src/styles.css`。

| 语义类            | 默认尺寸 | 使用位置                                     |
| ----------------- | -------: | -------------------------------------------- |
| `text-caption-xs` |     12px | 图表刻度等少量紧凑标记，不用于正文和操作按钮 |
| `text-caption`    |     13px | 时间、证券代码、计数和元信息                 |
| `text-label`      |     14px | 表单标签、按钮、表头                         |
| `text-table`      |     14px | 表格和记录卡片数据                           |
| `text-body-sm`    |     14px | 紧凑说明、卡片辅助正文                       |
| `text-body`       |     16px | 正文、表单说明、移动输入框                   |
| `text-title-sm`   |     18px | 小标题和摘要数值                             |
| `text-title`      |     20px | 面板标题                                     |
| `text-heading`    |     28px | 页面和弹窗标题                               |
| `text-display`    |     36px | 少量核心数字                                 |

- 正文使用 `text-foreground`，辅助文字使用 `text-muted-foreground`，次要元信息使用 `text-subtle`；不要再次叠加透明度。
- 橙色文字使用 `text-primary-text`；实心主按钮使用 `bg-primary` 配合 `text-primary-foreground`。
- 涨跌使用 `text-market-up` / `text-market-down`；保留正负号、箭头或文字表达，避免只凭颜色理解状态。
- 多来源样式通过 `cn()` 合并。组件密度优先通过 `size` / `density` 参数选择，不在页面添加 `!text-*` 或数值字号覆盖。
- 字体族集中配置；业务专用图表、日历格子和日记阅读排版保留专用布局，共享字号和颜色。

## 3. 公共组件的使用方式

| 需要调整的内容                 | 统一入口                                                                              |
| ------------------------------ | ------------------------------------------------------------------------------------- |
| 页面外壳、页面留白和滚动规则   | `components/workspace.css`、`PageContainer` 的 `document / workspace / embedded` 布局 |
| 卡片边框、圆角、背景和阴影     | `components/ui/card.tsx` 中的 `Card` 与 `cardVariants`                                |
| 页面标题、紧凑标题             | `PageHeader` 的 `density` 参数                                                        |
| 输入框、选择框、日期触发器     | `formControlVariants`；普通输入使用 `Input / Select / Textarea`                       |
| 表格表头、行和单元格           | `components/ui/table.tsx`；业务列与操作保留在功能模块                                 |
| 数据表格的窄屏展示             | `DataTable.mobile`，或业务需要选择行时复用 `RecordCard`                               |
| 指标标签和数值、证券名称和代码 | `Metric`、`InstrumentCell`                                                            |
| 弹窗与长表单                   | `DialogHeader / DialogBody / DialogFooter`，避免另写固定高度外壳                      |
| 第三方网页                     | `ExternalContentFrame`；证券详情使用 `StockDetail`                                    |

例如，为共享表格声明移动端重点字段，剩余数据列自动放入展开区，动作仍复用原列的渲染与回调：

```tsx
<DataTable
  columns={columns}
  data={holdings}
  getRowId={(holding) => holding.id}
  empty={<EmptyState title="暂无持仓" />}
  mobile={{
    titleColumn: "instrument",
    primaryColumns: [
      "latest",
      "market_value",
      "floating_gain",
      "floating_gain_percent",
    ],
    actionColumn: "actions",
  }}
/>
```

工作区采用文档自然增高、数据区域内部滚动的组合。桌面表格内容区为 12–36rem；备注和提示变长时页面继续增高。投资日记在足够大的桌面视口保留双栏独立滚动，窄屏或低高度视口改用文档滚动。

## 5. 验证边界与后续维护

浏览器检查使用本地、符合 Schema 的示例响应，排序写请求由测试拦截；未修改真实账户或业务数据。第三方 iframe 使用占位内容，只验证本项目提供的外壳、返回与打开入口，第三方网页内部的字体、颜色、加载限制不能由本项目样式控制。

后续新增功能应直接采用上表的组件入口，并执行 `pnpm run check`。涉及数据展示或长表单时，同时复查长文本、窄屏、低高度与字号放大；真实数据源和外部站点变化时，再按对应功能进行联调。
